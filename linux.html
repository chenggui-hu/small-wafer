一、Linux 发行版本对比

Linux 只是内核，日常说的「装个 Linux」其实是在选发行版。主流发行版大体分成两大流派：Debian 系（用 apt / .deb）和 Red Hat 系（用 rpm / yum / dnf）。看包管理器基本就能判断属于哪一支。

发行版所属流派包管理最新版本 / 发布时间
Ubuntu Debian 系 apt / dpkg 26.04 LTS（2026-04 发布，标准支持 5 年 + Pro 扩展至 10 年）
Debian Debian 系 apt / dpkg 13「Trixie」（2025-08 发布，约每 2 年一个大版本）
Red Hat（RHEL） Red Hat 系 dnf / yum / rpm 10.2（2026-05 发布，每 6 个月一个小版本）
CentOS Red Hat 系 dnf / yum / rpm Stream 10（滚动更新，RHEL 10 的上游预发布；生产环境多迁往 Rocky / AlmaLinux 10.2）
版本数据截至 2026-10。查最新版本：cat /etc/os-release；Ubuntu 版本号「年.月」规则，LTS 每 2 年 4 月发布一次。

同一个操作，两个流派怎么写

操作Debian 系（Ubuntu / Debian）Red Hat 系（RHEL / CentOS）
更新软件索引apt updateyum makecache
安装软件apt install nginxyum install nginx
升级已装软件apt upgradeyum update
卸载软件apt remove nginxyum remove nginx
服务管理systemctlsystemctl
防火墙ufwfirewalld

二、常用指令

日常登录服务器后最常用的一批命令，覆盖查看目录、切换路径、系统信息、权限调整等场景。

指令作用常用示例
ll ls -l 的常用别名，以长格式列出目录内容：权限、属主、大小、修改时间。 ll -h 人类可读大小 · ll -a 含隐藏文件
cd 切换当前工作目录。 cd /var/log · cd ~ 家目录 · cd - 上一个目录 · cd .. 上级
pwd 打印当前工作目录的绝对路径。 pwd · pwd -P 显示真实物理路径（解析软链接）
mkdir 创建目录。 mkdir logs · mkdir -p a/b/c 递归创建 · mkdir -m 755 bin 指定权限
cp 复制文件或目录。 cp a.txt /tmp/ · cp -r dir1 dir2 递归复制目录 · cp -a src dst 保留权限/时间戳等属性
mv 移动文件或目录，也用于重命名。 mv a.txt /tmp/ 移动 · mv old.txt new.txt 重命名 · mv -i a b 覆盖前先询问
who 查看当前登录系统的用户，含终端、登录时间与来源 IP。 who · who -b 系统上次启动时间
uname 显示系统与内核信息。 uname -a 全部 · uname -r 内核版本 · uname -m 硬件架构
date 显示或格式化系统时间。 date · date "+%Y-%m-%d %H:%M:%S" · date -d "yesterday" +%F
whereis 查找命令对应的二进制、源码与 man 手册路径。 whereis ls · whereis -b python 只找二进制
id 显示用户的 UID、GID 及所属附加组，常用于确认权限。 id · id nginx 查看指定用户
userdel 删除用户账号（配合 useradd 使用）。 userdel tom 仅删账号 · userdel -r tom 连同家目录与邮件一起删
passwd 设置或修改用户登录口令。 passwd 改自己口令 · sudo passwd tom 管理员改他人 · passwd -l tom 锁定账号
chmod 修改文件 / 目录的读写执行权限。 chmod 755 run.sh · chmod u+x a.sh · chmod -R 644 ./conf
top 实时进程监控：CPU、内存占用、负载、各进程资源消耗，排障第一入口。按 q 退出。 top · top -u tom 只看某用户 · P 按 CPU 排序 · M 按内存排序 · 交互内 k 杀进程
ifconfig 查看 / 配置网卡（IP、掩码、MAC）。等价于 Windows 的 ipconfig；新系统推荐用 ip 命令族。 ifconfig · ifconfig eth0 指定网卡 · ip addr 现代写法 · ip a show eth0
权限数字速记：读 r=4、写 w=2、执行 x=1，三者相加即为一位数字。例如 755 表示属主 rwx、同组 r-x、其他 r-x；644 表示属主 rw-、其余只读。
绝对路径 vs 相对路径：绝对路径以 / 开头，从根目录写起，与当前所在位置无关，如 /var/log/nginx；相对路径不以 / 开头，从当前目录写起，如 ./conf、../logs、bin/run.sh。其中 . 表示当前目录、.. 表示上级目录、~ 表示当前用户家目录。用 pwd 可随时确认自己「站在哪」。

三、目录结构与分区用途

Linux 的目录是一棵以 / 为根的树，每个标准目录各司其职（这套规范叫 FHS）。了解它们「放什么」，排障和部署时就不会瞎找。

目录用途放置什么文件
/bin 基础命令 所有用户都能用的最基础命令：ls、cp、cat、bash 等。多数新发行版已并入 /usr/bin，/bin 只是软链接。
/boot 系统启动 内核 vmlinuz、initramfs 镜像、GRUB 引导配置与模块。常单独分区（约 200MB~1GB），便于多内核管理。
/etc 配置文件 几乎全部系统与服务的配置：/etc/nginx、/etc/ssh、/etc/passwd、/etc/fstab。纯文本，改前先备份。
/home 普通用户家目录 每个用户一个子目录（/home/tom），存放个人文件与个人配置（.bashrc 等）。常单独分区，重装系统可保留数据。
/lib 共享库与内核模块 程序运行依赖的动态链接库（.so）与内核模块 /lib/modules。现代发行版多数已并入 /usr/lib。
/opt 可选 / 第三方软件 手动安装的独立第三方软件，如 /opt/google/chrome、/opt/apps。与系统包管理互不干扰，便于整体删除。
/usr 用户级程序与资源 只读的系统程序、库与文档：/usr/bin、/usr/lib、/usr/share、/usr/local。通常是体积最大的目录之一。
/var 可变数据 经常变化的数据：日志 /var/log、缓存 /var/cache、队列 /var/spool、网站数据 /var/www。常单独分区，防止日志写满拖垮根分区。
分区建议：生产环境常把 /home、/var、/opt 单独分区，避免某个目录被写满而拖垮整个系统；/boot 独立则便于内核与引导管理。/etc 体积小却至关重要，一般留在根分区。

四、Vim 文本编辑

Vim 的核心是「模式切换」：先按 Esc 回到命令模式，再按 : 进入末行模式。记住这一点，其余都是肌肉记忆。

三种基本模式

模式说明进入方式
命令模式（Normal） 默认模式，移动光标、复制、删除、粘贴都在这里完成。 打开文件即进入；任意模式按 Esc 返回
插入模式（Insert） 输入与修改文本。 i a o O 等
末行模式（Command） 底部输入命令：保存、退出、替换、跳转。 命令模式下按 :

常用操作

分类按键作用
进入插入i / a在光标前 / 光标后插入
进入插入o / O在下方 / 上方新开一行插入
保存退出:w :q :wq :q!保存 / 退出 / 保存并退出 / 不保存强制退出
光标移动h j k l左 / 下 / 上 / 右
光标移动gg / G跳到首行 / 末行
光标移动:n跳到第 n 行（如 :20）
光标移动0 / $行首 / 行尾
编辑dd / yy / p删除（剪切）当前行 / 复制当前行 / 粘贴
编辑u / Ctrl + r撤销 / 重做
编辑x / dw删除光标处字符 / 删除一个单词
查找/word · n · N向下搜索 word；n 下一个、N 上一个
替换:s/old/new/g替换当前行全部匹配
替换:%s/old/new/g全文替换
替换:%s/old/new/gc全文替换，逐个确认

五、Shell 语法

Shell 脚本本质是把命令按顺序写进文件，再加一点变量、判断、循环和函数。下面是最常用的一套骨架。

Shebang 与变量

#!/bin/bash
name="wafer"                  # 赋值：等号两边不能有空格
echo "hello, $name"           # 双引号会解析变量
echo 'hello, $name'           # 单引号原样输出
export PATH="$PATH:/opt/bin"  # 导出为环境变量，子进程可见

特殊变量

echo "$0"   # 脚本名
echo "$1"   # 第 1 个参数
echo "$#"   # 参数个数
echo "$?"   # 上一条命令的退出码（0 表示成功）
echo "$$"   # 当前脚本的 PID

条件判断

if [ "$num" -gt 10 ]; then
  echo "大于 10"
elif [ "$num" -eq 10 ]; then
  echo "等于 10"
else
  echo "小于 10"
fi

[ -f /etc/hosts ] && echo "是普通文件"
[ -d /var/log ]   && echo "是目录"
[ -z "$str" ]     && echo "字符串为空"

数值比较用 -gt -lt -eq -ne -ge -le；字符串比较用 = !=；文件测试用 -f 文件、-d 目录、-e 存在。

循环

for i in $(seq 1 5); do
  echo "第 $i 次"
done

while read -r line; do
  echo "$line"
done < list.txt

函数

greet() {
  local who="$1"          # local 声明局部变量
  echo "hello, $who"
}
greet "wafer"

重定向与管道

cmd > out.log          # 覆盖写入标准输出
cmd >> out.log         # 追加写入
cmd > out.log 2>&1    # 标准输出与错误一起写入文件
cmd1 | cmd2            # 管道：前者输出作为后者输入
cmd1 && cmd2          # 前者成功才执行后者
cmd1 || cmd2           # 前者失败才执行后者

六、Crontab 定时

Crontab 用来配置周期性任务，格式是「五个时间字段 + 一条命令」。

时间字段含义

* * * * *  command
│ │ │ │ │
│ │ │ │ └─ 星期 (0-7，0 和 7 都表示周日)
│ │ │ └─── 月份 (1-12)
│ │ └───── 日   (1-31)
│ └─────── 时   (0-23)
└───────── 分   (0-59)

基本操作

crontab -e   # 编辑当前用户的定时任务
crontab -l   # 列出已有的任务
crontab -r   # 删除全部任务（慎用）

常用示例

*/5 * * * *    /opt/script/check.sh     # 每 5 分钟执行
0 2 * * *      /opt/script/backup.sh    # 每天 02:00
30 9 * * 1-5   /opt/script/report.sh    # 工作日 09:30
0 0 1 * *      /opt/script/monthly.sh   # 每月 1 号 00:00
@reboot        /opt/script/start.sh     # 开机启动时执行
@daily         /opt/script/clean.sh     # 等价于 0 0 * * *
  • 通配符：* 任意值、, 枚举（1,15）、- 范围（1-5）、/ 步长（*/5 每 5 个单位）。
  • 用绝对路径：cron 的 PATH 很精简，脚本内命令写全路径，或在开头加 PATH=/usr/local/bin:/usr/bin:/bin。
  • 重定向输出：命令后加 >> /var/log/job.log 2>&1，否则输出会作为邮件发送。
  • 确认服务在跑：systemctl status crond（Debian / Ubuntu 上是 cron）。
  • 用户隔离：每个用户有独立 crontab，root 的任务用 sudo crontab -e。
