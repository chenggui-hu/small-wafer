一、基础语法

Python 是动态类型语言：变量不用声明类型，赋什么就是什么。核心内置类型就 6 个，吃透它们就够日常用了。

数据类型和变量

类型写法示例要点
整数 intn = 10 · a = 0b1010 二进制无位数限制，天然支持大整数
浮点数 floatx = 3.14 · 1.23e9有精度误差，比较用 abs(a-b) < 1e-9
字符串 strs = "hello"不可变，支持切片 s[1:3]
布尔 boolTrue / False布尔运算 and / or / not
空值 Noner = None不是 0 也不是空串，表示「没有值」
除法10 / 3 · 10 // 3 · 10 % 3/ 得浮点，// 地板除，% 取余

字符串与编码

s = "中文abc"
len(s)              # 5：按字符数，不是字节数
s.encode('utf-8')   # str -> bytes，中文占 3 字节
b.decode('utf-8')   # bytes -> str
ord('A')            # 65：字符 -> 码位
chr(66)             # 'B'：码位 -> 字符
f"我叫{name}，今年{age}岁"   # f-string 格式化，首选
"{:.2f}".format(3.14159)     # '3.14'，保留两位小数
记一条：str 是字符序列、bytes 是字节序列。网络和文件读进来的都是 bytes，先 decode 再处理；写出去前 encode。统一用 UTF-8 基本不会乱码。

list 和 tuple

langs = ['python', 'java', 'c++']
langs.append('go')      # 尾部追加
langs.insert(1, 'rust') # 指定位置插入
langs.pop()             # 删除末尾元素
langs[0]                # 'python'，索引从 0 开始
langs[-1]               # 最后一个
langs[1:3]              # 切片，取索引 1、2

point = (3, 5)          # tuple 不可变，一旦定义不能改
x, y = point            # 解包赋值

条件判断

age = 20
if age >= 18:
    print('adult')
elif age >= 6:

# 只要 x 是非零数值、非空字符串、非空 list/dict，就为 True

循环

for name in ['A', 'B', 'C']:    # for-in 遍历
    print(name)
for i in range(5):              # 0 1 2 3 4
    print(i)
for i, v in enumerate(lst):     # 同时要下标和值
    print(i, v)

n = 100
while n > 0:                    # while 循环
    n = n // 2
    if n == 10:
        break                   # 提前退出；continue 跳过本轮

dict 和 set

d = {'Michael': 95, 'Bob': 75}
d['Tracy'] = 85            # 新增 / 覆盖
d.get('Tom', -1)           # key 不存在返回 -1，不报错
d.pop('Bob')               # 删除
for k, v in d.items():     # 遍历键值
    print(k, v)

s = {1, 2, 3}              # set：key 集合，自动去重
s.add(4); s.remove(1)
s1 & s2                    # 交集；s1 | s2 并集

二、函数

函数是复利最高的抽象：一段逻辑封装好，到处调用。参数规则是面试和排错的高频点。

调用函数

abs(-100)          # 100
max(1, 2, 3)       # 3
int('12')          # 12，类型转换也是函数
isinstance('a', str)   # True，类型检查
# 不知道有什么内置函数：help(abs) 看 help

定义函数

def my_abs(x):
    if not isinstance(x, (int, float)):
        raise TypeError('bad operand type')
    if x >= 0:
        return x
    return -x

def nop():          # 空函数先占位
    pass

函数的参数

参数类型写法说明
位置参数def f(x, y)按顺序传入，数量位置都要对
默认参数def f(x, n=2)必选在前；默认值必须是不可变对象
可变参数def f(*nums)收进 tuple，调用可传任意个
关键字参数def f(**kw)收进 dict，扩展函数能力而不破坏接口
 
def enroll(name, gender, age=6, city='Beijing'):
    print(name, gender, age, city)

enroll('Sarah', 'F')              # 默认参数生效
enroll('Bob', 'M', age=8)         # 覆盖默认值

def calc(*numbers):
    total = 0
    for n in numbers:
        total += n
    return total

calc(1, 2, 3)          # 6
nums = [1, 2, 3]
calc(*nums)            # 已有 list 加 * 即可传入

递归函数

def fact(n):
    if n == 1:
        return 1
    return n * fact(n - 1)

fact(5)        # 120。注意：层数过深会栈溢出（默认约 1000 层）
坑位提醒：默认参数千万别用可变对象——def f(lst=[]) 的 lst 会在多次调用间共享，改成 lst=None 再在函数体内新建。

# 实战样例：汇总当前目录所有 Excel 的第一个 sheet
import pandas as pd
from pathlib import Path

rows = []
for f in Path('.').glob('*.xlsx'):
    rows.append(pd.read_excel(f))
pd.concat(rows).to_excel('汇总.xlsx', index=False)

四、爬虫常用库

爬虫三步走：请求（requests）→ 解析（bs4 / re / lxml）→ 存储（csv / pandas）。动静分离：静态页 requests 就够，动态渲染上浏览器自动化。

库定位典型代码
requests HTTP 请求事实标准，简单直接 r = requests.get(url, headers=hd) · r.text
beautifulsoup4 HTML 解析，按标签 / class 抽数据 soup.select('div.title a') · t.get_text()
lxml 高速解析器，配合 bs4 或 XPath 使用 BeautifulSoup(html, 'lxml')
re 正则提取，处理非结构化文本 re.findall(r'\d{4}-\d{2}-\d{2}', text)
pandas 表格抓取一步到位，存 Excel / CSV pd.read_html(url) · df.to_csv('out.csv')
selenium / playwright JS 渲染页面、需要登录 / 滚动加载时上真浏览器 driver.get(url) · driver.find_element('id', 'kw')
scrapy 大型爬虫框架：调度、并发、管道一条龙 scrapy startproject demo · scrapy crawl spider1 
# 最小可用爬虫：抓标题并存 CSV
import requests
from bs4 import BeautifulSoup
import pandas as pd

hd = {'User-Agent': 'Mozilla/5.0'}
soup = BeautifulSoup(requests.get(url, headers=hd).text, 'lxml')
titles = [t.get_text() for t in soup.select('h2 a')]
pd.DataFrame({'标题': titles}).to_csv('titles.csv', index=False)
