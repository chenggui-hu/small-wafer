我的装机清单

工作与日常离不开的桌面软件，按场景归类。这是个清单，不是教程。

一、找东西

Everything

装机第一件事就装上的软件。Windows 自带的搜索每次都让人怀疑电脑没装固态，换上 Everything，输入文件名秒出结果，连隐藏文件都能搜到。

7-Zip

开源瑞士军刀，命令行友好。不到 10MB，压缩解压干净利索。

二、截图录屏

Snipaste

用了五年的截图工具。F1 截图、F3 贴图，截图后可以钉在屏幕上对照着写东西。改颜色、加箭头、加马赛克，几秒搞定。

PixPin

后起之秀，长截图、滚动截图、GIF 录制都很好用。两个互补，Snipaste 处理静态标注，PixPin 处理长内容。

Bandicam

录游戏和高帧率操作，画质可控，体积小。

三、看图

IrfanView

Windows 上最被低估的软件之一。不到 5MB，却能打开几乎所有图片格式，批量重命名、批量转格式，速度飞快。日常看图、修图、轻度处理都用它。

四、播放和演示

PotPlayer

本地视频播放的事实标准。解码全、设置细、支持外挂字幕。装了它，Windows 自带播放器基本可以卸载。

ZoomIt

微软出品的小工具。Ctrl+1 放大屏幕、Ctrl+2 进入标注模式、Ctrl+3 进入白板模式。直播、录课、会议分享都用得上。

五、下载和网盘

IDM

Windows 下载管理的老大哥。多线程、断点续传、浏览器集成，下载大文件基本用它。配合浏览器插件，几乎所有下载场景都能接管。

夸克网盘

88VIP 附赠的会员，海鲜市场 10￥/年。

六、文档和代码

WPS

日常文档的主力。从 Word、Excel 到 PDF、流程图，一个软件搞定。

Python + VS Code

七、清理和网络

Geek Uninstaller

干净卸载的工具。Windows 自带的卸载经常留一堆残留，它能扫干净注册表和文件夹。体积小、免安装、免费。

Clash party

网络工具，开源、可视化、规则丰富。具体怎么用，懂的自然懂；不懂也别问，这是个清单不是教程。
